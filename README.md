# Titanic Seaborn Visualization

This project performs exploratory data analysis (EDA) on the Titanic dataset using Seaborn and Matplotlib.

## 📊 Overview

The dataset is loaded using Seaborn's built-in datasets. The project focuses on visualizing:

- Age distribution by passenger class
- Fare distribution by passenger class

## 🛠️ Technologies Used

- Python
- Seaborn
- Matplotlib
